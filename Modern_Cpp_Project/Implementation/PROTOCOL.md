# Protocol Messages

## Temperature
`TEMP:25.5`

## Threshold
`THRESHOLD:30.0`

## LED State
`LED:ON` or `LED:OFF`


### Normal Operation Example

```
┌─────────────┐                    ┌──────────┐                     ┌───────────────┐
│   Sensor     │                    │  Client   │                     │  Host Server   │
└──────┬──────┘                    └──┬───────┘                     └────┬──────────┘
       │                                │                                   │
       │  TEMP:25.5 (UDP 9081)          │                                   │
       │────────────────────────────>│                                   │
       │                                │  TEMP:25.5 (UDP 8081)             │
       │                                │───────────────────────────────>│
       │                                │                                   │
       │                                │  THRESHOLD:30.0 (TCP 8080)        │
       │                                │<───────────────────────────────│
       │                                │                                   │
       │  TEMP:31.0 (UDP 9081)          │                                   │
       │────────────────────────────>│                                   │
       │                                │  TEMP:31.0 (UDP 8081)             │
       │                                │───────────────────────────────>│
       │                                │                                   │
       │                                │  [Temp > Threshold: LED ON]       │
       │                                │                                   │
       │  LED:ON (TCP 9080)             │                                   │
       │<────────────────────────────│                                   │
       │                                │  LED:ON (TCP 8080)                │
       │                                │───────────────────────────────>│
```
